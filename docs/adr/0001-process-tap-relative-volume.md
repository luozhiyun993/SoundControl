# 用 Core Audio Process Tap 实现按应用音量，应用音量取相对值

macOS 不提供按应用调音量的能力。我们选择 macOS 14.2+ 的 Core Audio Process Tap：截获受控应用的音频、静音原声、按应用音量重新输出到默认设备；而不是安装虚拟音频驱动（如 BackgroundMusic 的做法）。原因是只自用、系统已是 macOS 15，免驱动安装/签名/维护的成本远比兼容旧系统重要。

## Consequences

- 最低系统版本 macOS 14.2，需要用户授予"系统音频录制"权限。
- 重放音频仍经过输出设备，因此应用音量只能是**相对于系统音量**的比例，做不到独立于系统音量的"绝对音量"（补偿方案会失真，接管系统音量又会波及未添加的应用）。
- App 退出或崩溃时截获失效，受控应用会回到原始响度；这一点被接受，不做额外保护。
